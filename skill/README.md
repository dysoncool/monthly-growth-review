# monthly-growth-review

给你的月度成长出一份复盘的通用技能。

- 五格档位（刚冒头／开始积累／初有效果／值得重视／略有小成）
- 外用／内修分组，内修单薄要给提醒
- 五节结构：结论、四数、五问、收尾、页脚
- 三段自检：结构 19 项、脱敏、连续性
- 出稿后挂月末定时任务，说一次以后自动

## 文件

| 路径 | 用途 |
|---|---|
| `SKILL.md` | 方法与口径 |
| `INSTALL.md` | 安装、首次运行、定时任务 |
| `templates/monthly-review-blank.html` | 可直接改的样板页（示例数据） |
| `scripts/check_page.py` | 页面结构与版式自检（19 项） |
| `scripts/check_clean.py` | 脱敏检查 |
| `scripts/check_continuity.py` | 月份连续性检查 |

## 三条不许

不自带任何真实客户信息；不写死任何绝对路径；不允许断月出稿。
