# 安装与首次运行

三步装好，十分钟内能出第一份月报。

## 1. 放好目录

把整个技能目录放到你的技能路径下（例如 `skills/consulting/monthly-growth-review-beta/`），然后建一个放月报的目录：

```
mkdir -p <你的库>/monthly-review
```

`<你的库>` 就是后面所有命令里的 `--base`。

## 2. 抄一份模板

```
cp templates/monthly-review-blank.html <你的库>/monthly-review/2026-01-月度成长总结.html
```

打开它，把示例内容改成你自己的：姓名、日期、四条关键数、每一句证据。
**结构不要动**——五节、四数、五格、外用/内修分组、提醒块，都是校验会查的。

## 3. 自检

```
python3 scripts/check_page.py <你的库>/monthly-review/2026-01-月度成长总结.html
python3 scripts/check_clean.py <你的库>/monthly-review/2026-01-月度成长总结.html --names 你的真名
python3 scripts/check_continuity.py --base <你的库>/monthly-review --start 2026-01
```

三条全绿才算完成。`check_page` 查结构与版式，`check_clean` 查有没有漏出来的真名、路径、电话，`check_continuity` 查月份有没有断。

## 4. 挂定时任务（说一次，以后自动）

交给你的 AI 助手（或自己配 cron），要求写死这五条：

1. 每月**最后一天 21:00** 触发（cron `0 21 28-31 * *`）；不是最后一天就静默，不发任何字。
2. 启动先跑 `check_continuity.py`，缺哪月补哪月，不许跳月。
3. 当月已出过 → 跳过；要新版加 `-vN`，不覆盖旧版。
4. **失败不许静默**：取数或脚本报错，必须发一句「今晚没出成，原因是 X」。
5. 发文件必须写 `MEDIA:<绝对路径>`。

## 5. 每月怎么跑

1. 取数：日记、工作记录、聊天回执，拉一张带日期的事件清单。
2. 标「有结果／没结果」。
3. 五问：做成了什么／势能到哪一格／哪条路越走越省力／哪里在漏／怎样算站住。
4. 出稿 → 三条自检 → 发文件 → 在 `<你的库>/README.md` 登记。

## 常见坑

- **只出当月、不回看历史**：连续性一断，积累就看不出来。先补最早那期。
- **把阅读量当成果**：有人看只算「刚冒头」，有人动手才算「初有效果」。
- **内修空着不说**：内修单薄必须写提醒块，点名缺的读书、静坐、站桩。
- **金额混进正文**：自用版不设「钱从哪来」一节，钱只进四个关键数。
